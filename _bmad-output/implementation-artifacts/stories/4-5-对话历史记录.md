# Story 4.5: 对话历史记录

Status: review

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

作为登录用户,
我希望查看我的对话历史,
以便我可以回顾之前的问题和解答。

## Acceptance Criteria

1. **Given** 用户已登录
   **When** 打开 AI 助手面板
   **Then** 自动加载并显示最近的对话记录（最近 50 条）
   **And** 消息按时间顺序排列
   **And** 显示加载状态（旋转指示器）
   **And** 历史加载失败时显示友好提示「加载历史记录失败，请重试」

2. **Given** 用户已加载对话历史
   **When** 发送新消息
   **Then** 新消息追加到历史末尾
   **And** 对话历史自动作为上下文传给 AI（复用现有 conversationHistory 机制）
   **And** 后端继续记录到 chat_logs 表

3. **Given** 用户已登录且有对话历史
   **When** 点击「清空对话」按钮
   **Then** 弹出确认对话框「确定要清空所有对话历史吗？此操作不可恢复」
   **And** 确认后调用后端接口删除数据库记录
   **And** 前端消息列表清空
   **And** 显示「对话历史已清空」提示

4. **Given** 用户未登录
   **When** 打开 AI 助手面板
   **Then** 不加载对话历史（显示空状态或登录提示）
   **And** 「清空对话」按钮不可见或禁用

5. **Given** 用户首次使用 AI 助手（无历史记录）
   **When** 打开 AI 助手面板
   **Then** 显示空状态（与现有空状态一致，展示快捷术语标签）
   **And** 不显示「清空对话」按钮

static async findByUserId(
  userId: number,
  limit = 50
): Promise<Array<{ role: 'user' | 'assistant'; content: string; created_at: Date }>> {
  const query = `
    SELECT role, content, created_at
    FROM chat_logs
    WHERE user_id = ?
    ORDER BY created_at ASC
    LIMIT ?
  `;
  const [rows] = await pool.execute(query, [userId, limit]);
  return rows as Array<{ role: 'user' | 'assistant'; content: string; created_at: Date }>;
}

// ChatLogsModel.deleteByUserId
static async deleteByUserId(userId: number): Promise<void> {
  const query = 'DELETE FROM chat_logs WHERE user_id = ?';
  await pool.execute(query, [userId]);
}

// AIController.getHistory
static async getHistory(req: Request, res: Response): Promise<void> {
  const userId = req.session?.userId;
  if (!userId) {
    res.status(401).json({ code: 'UNAUTHORIZED', message: '请先登录' });
    return;
  }

  try {
    const messages = await ChatLogsModel.findByUserId(userId, 50);
    res.json({
      code: 'SUCCESS',
      data: { messages },
    });
  } catch (error) {
    logger.error('获取对话历史失败:', error);
    res.status(500).json({ code: 'INTERNAL_ERROR', message: '获取对话历史失败' });
  }
}

// AIController.clearHistory
static async clearHistory(req: Request, res: Response): Promise<void> {
  const userId = req.session?.userId;
  if (!userId) {
    res.status(401).json({ code: 'UNAUTHORIZED', message: '请先登录' });
    return;
  }

  try {
    await ChatLogsModel.deleteByUserId(userId);
    res.json({ code: 'SUCCESS', message: '对话历史已清空' });
  } catch (error) {
    logger.error('清空对话历史失败:', error);
    res.status(500).json({ code: 'INTERNAL_ERROR', message: '清空对话历史失败' });
  }
}

// frontend/src/api/ai.ts
import type { ChatRole } from '@/types/ai-chat';

export async function fetchChatHistory(): Promise<
  Array<{ role: ChatRole; content: string; created_at: string }>
> {
  const response = await fetch('/api/ai/history', {
    method: 'GET',
    credentials: 'include',
  });

  if (!response.ok) {
    if (response.status === 401) throw new Error('UNAUTHORIZED');
    throw new Error('加载历史记录失败');
  }

  const result = await response.json();
  return result.data.messages;
}

export async function clearChatHistory(): Promise<void> {
  const response = await fetch('/api/ai/history', {
    method: 'DELETE',
    credentials: 'include',
  });

  if (!response.ok) {
    if (response.status === 401) throw new Error('UNAUTHORIZED');
    throw new Error('清空历史记录失败');
  }
}

```typescript
import { fetchChatHistory, clearChatHistory } from '@/api/ai';

export function useAIChat() {
  // ... 现有状态 ...
  const isLoadingHistory = ref(false);
  const historyError = ref<string | null>(null);

  async function loadHistory() {
    if (!userStore.isLoggedIn) return;
    if (messages.value.length > 0) return; // 避免重复加载

    isLoadingHistory.value = true;
    historyError.value = null;

    try {
      const history = await fetchChatHistory();
      messages.value = history.map((item, index) => ({
        id: `hist-${Date.now()}-${index}`,
        role: item.role,
        content: item.content,
        timestamp: new Date(item.created_at).getTime(),
      }));
    } catch (error) {
      historyError.value = '加载历史记录失败，请重试';
      console.error('加载对话历史失败:', error);
    } finally {
      isLoadingHistory.value = false;
    }
  }

  async function clearMessages() {
    if (abortController) {
      abortController.abort();
      abortController = null;
    }

    try {
      if (userStore.isLoggedIn) {
        await clearChatHistory();
      }
    } catch (error) {
      ElMessage.error('清空历史记录失败');
    }

    messages.value = [];
    status.value = 'idle';
  }

  // ... 返回新增状态和方法 ...
  return {
    messages, status, isLoadingHistory, historyError,
    sendMessage, clearMessages, retryLast, stopStreaming, loadHistory,
  };
}
```

### 关键设计决策

1. **不加 aiLimiter**：`GET /ai/history` 和 `DELETE /ai/history` 不走 AI 生成限流，它们只是数据查询/删除操作。全局 `express-rate-limit` 已足够保护
2. **仅加载最近 50 条**：chat_logs 表没有会话概念，加载全部历史可能数据量过大。50 条足够覆盖近期对话，同时避免性能问题
3. **仅在消息数组为空时加载历史**：防止用户已有当前对话时被历史覆盖。如果用户在当前页面已发送消息，打开/关闭面板不会重新加载
4. **`clearMessages` 改为异步**：需要等待后端删除完成后再清空前端状态，但即使后端失败也清空前端（用户视角已清空，刷新后才暴露）
5. **历史消息 id 前端生成**：后端 `chat_logs` 表的 `id` 不暴露给前端，前端用 `hist-${timestamp}-${index}` 生成，符合现有 `ChatMessage.id` 字符串格式
6. **不修改表结构**：现有 `chat_logs` 表完全满足需求，不需要 `session_id` 或 `conversation_id` 字段。所有消息属于一个连续对话流

### 性能考虑

- 历史查询使用 `idx_user_id` 索引（Story 4-2 已创建），`ORDER BY created_at ASC` 使用 `idx_created_at` 索引
- `LIMIT 50` 防止大数据量查询
- 加载历史为异步操作，不阻塞 AI 面板打开动画
- 仅首次打开面板时加载，避免重复请求

### 安全考虑

- 两个新接口均校验 `req.session.userId`，未登录返回 401
- `findByUserId` / `deleteByUserId` 均使用参数化查询，防 SQL 注入
- 用户只能查询/删除自己的记录（通过 `WHERE user_id = ?` 隔离）
- 清空操作需要确认对话框，防止误触
