# Story 2.1: 知识内容列表页

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 用户,
I want 浏览 6 大领域的知识内容,
so that 我可以学习部署相关知识。

## Acceptance Criteria

1. **Given** 数据库中有知识内容数据  
   **When** 访问知识内容页面 `/contents`  
   **Then** 显示 6 大领域分类标签（构建、平台、服务器、自动化、域名、容器）

2. **Given** 用户已选择某个领域标签  
   **When** 页面加载该领域内容  
   **Then** 显示该领域的内容卡片列表  
   **And** 卡片显示标题、层级标签（Lv1-Lv5）、简介

3. **Given** 用户未选择任何领域  
   **When** 页面默认加载  
   **Then** 显示全部内容（或默认显示第一个有内容的领域）

4. **Given** 内容列表加载  
   **When** 数据为空  
   **Then** 显示友好空状态提示（如「暂无内容，敬请期待」）

## Dev Notes

### 关键复用点（禁止重复造轮子）

- **ContentsModel 已完整实现**：`backend/src/models/contents.model.ts` 已包含 `findAll()`、`findByDomain()`、`findByLevel()`、`search()`、`getStats()` 等方法。开发者**必须直接复用**，禁止创建新的内容查询逻辑。
  - `findAll(options)` 支持 `domain`、`level`、`search`、`page`、`limit` 参数
  - 返回格式：`{ contents: Content[], total: number, page: number, totalPages: number }`
  - JSON 字段（`examples`、`tags`）已在模型内部自动解析

- **DatabaseService 已就位**：`backend/src/services/database.service.ts` 提供通用查询/执行方法，ContentsModel 已基于它实现。

- **数据库表结构**（`contents`）：
  ```sql
  id INT PK AUTO_INCREMENT
  domain ENUM('build','platform','server','automation','domain','container')
  level INT
  title VARCHAR(255)
  description TEXT
  content LONGTEXT
  examples JSON
  tags JSON
  created_at TIMESTAMP
  updated_at TIMESTAMP
  ```

- **后端路由模式**：参考 `backend/src/routes/auth.routes.ts` 和 `backend/src/app.ts` 中路由注册方式。新路由使用 `app.use('/api', contentRoutes)` 挂载。

- **前端 API 模式**：参考 `frontend/src/api/auth.ts`，使用 `axios.create({ baseURL, withCredentials: true })`。

- **前端 Store 模式**：参考 `frontend/src/stores/user.ts`，使用 Pinia setup store 语法。

- **路由守卫已就位**：`frontend/src/router/index.ts` 已配置 `router.beforeEach`，新页面默认 `meta: { requiresAuth: false }`。

### 技术实现要点

- **后端 Controller 示例结构**：
  ```typescript
  import { Request, Response } from 'express';
  import { ContentsModel } from '../models/contents.model';

  export class ContentController {
    static async list(req: Request, res: Response) {
      const { domain, page = '1', limit = '20' } = req.query;
      const result = await ContentsModel.findAll({
        domain: domain as string,
        page: Number(page),
        limit: Number(limit),
      });
      res.json({ code: 'SUCCESS', data: result });
    }
  }
  ```

- **前端 ContentsView 结构建议**：
  - 顶部：`el-tabs` 横向排列 6 个领域标签，使用中文标签名
  - 中部：`el-row` + `el-col` 网格布局，`ContentCard` 列表
  - 加载中：`el-skeleton` 或 `v-loading`
  - 空状态：`el-empty`

- **ContentCard 建议 props**：
  ```typescript
  interface ContentCardProps {
    id: number
    title: string
    level: number
    description?: string
  }
  ```

- **领域中文映射**：
  ```typescript
  const domainLabels: Record<string, string> = {
    build: '构建',
    platform: '平台',
    server: '服务器',
    automation: '自动化',
    domain: '域名',
    container: '容器',
  }
  ```
