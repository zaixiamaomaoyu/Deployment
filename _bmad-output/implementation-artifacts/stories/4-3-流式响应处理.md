## Dev Notes

### 技术实现建议

1. **流式渲染优化**
   - 使用 `requestAnimationFrame` 优化 DOM 更新
   - 避免频繁的 React/Vue 重渲染
   - 考虑使用 `DocumentFragment` 批量更新

2. **打字动画**
   - CSS 动画：光标闪烁（`@keyframes blink`）
   - 平滑滚动：`scrollIntoView({ behavior: 'smooth', block: 'end' })`
   - 避免使用 `setInterval`，使用 `requestAnimationFrame`

3. **中断响应**
   - 使用 `AbortController` 中断 `fetch` 请求
   - 后端需要处理客户端断连（已在 Story 4-2 实现）
   - 前端状态管理：`isStreaming`、`isAborted`

4. **复制功能**
   - 使用 `navigator.clipboard.writeText()`
   - 降级方案：创建临时 `<textarea>` 元素
   - 复制成功后显示 Toast 提示
