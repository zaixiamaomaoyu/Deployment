# Story 2.5: 内容收藏功能

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 登录用户,
I want 在内容详情页收藏感兴趣的内容,
so that 我可以在收藏列表中快速找到它们。

## Acceptance Criteria

1. **Given** 用户已登录并进入内容详情页 `/contents/:id`
   **When** 页面加载完成
   **Then** 显示收藏按钮，并根据当前收藏状态展示「收藏」或「已收藏」

2. **Given** 用户已登录，按钮显示「收藏」（未收藏状态）
   **When** 用户点击收藏按钮
   **Then** 调用后端 `POST /api/favorites/:contentId/toggle`
   **And** 按钮状态切换为「已收藏」（实心星标）
   **And** 显示 `ElMessage.success('已收藏')`

3. **Given** 用户已登录，按钮显示「已收藏」
   **When** 用户再次点击按钮
   **Then** 调用后端 `POST /api/favorites/:contentId/toggle`
   **And** 按钮状态切换为「收藏」（空心星标）
   **And** 显示 `ElMessage.success('已取消收藏')`

4. **Given** 用户未登录
   **When** 进入详情页
   **Then** 不显示收藏按钮（或显示但点击提示「请先登录」，二选一实现，推荐：不显示）

5. **Given** 用户已登录但访问不存在的内容 ID
   **When** 页面加载
   **Then** 显示 404 状态（沿用 Story 2-4 既有逻辑），不发起收藏状态查询

6. **Given** 收藏接口返回 401（Session 过期）
   **When** 用户点击收藏
   **Then** 提示「登录已过期，请重新登录」并清除前端登录状态
   **And** 跳转到登录页（沿用 `useUserStore` 现有逻辑）

7. **Given** 收藏接口返回 500 或网络错误
   **When** 用户点击收藏
   **Then** 显示 `ElMessage.error('操作失败，请稍后重试')`
   **And** 按钮状态保持原状（不发生错误的状态翻转）

8. **Given** 用户快速连续点击收藏按钮（竞态）
   **When** 第一次请求尚未返回
   **Then** 后续点击应被忽略（按钮 loading 或禁用），防止重复请求造成状态错乱

9. **Given** 用户从详情页跳转到另一篇内容（路由参数变化）
   **When** `route.params.id` 变化
   **Then** 收藏状态需重新查询，且避免上一次请求的残留响应覆盖新状态（参考 Story 2-4 的 `isMounted + rawId` 守卫模式）

### 技术实现要点

**后端 favorites.controller.ts 结构：**
```typescript
import { Request, Response } from 'express';
import { FavoritesModel } from '../models/favorites.model';
import { ContentsModel } from '../models/contents.model';
import { logger } from '../utils/logger';

function parsePositiveContentId(value: string | undefined): number | null {
  if (!value) return null;
  const num = Number(value);
  if (Number.isNaN(num) || !Number.isInteger(num) || num < 1) return null;
  return num;
}

export class FavoriteController {
  /**
   * 切换收藏状态
   * POST /api/favorites/:contentId/toggle
   */
  static async toggle(req: Request, res: Response): Promise<void> {
    try {
      const userId = req.session?.userId;
      if (!userId) {
        res.status(401).json({ code: 'UNAUTHORIZED', message: '请先登录' });
        return;
      }

      const contentId = parsePositiveContentId(req.params.contentId);
      if (contentId === null) {
        res.status(400).json({ code: 'VALIDATION_ERROR', message: '无效的内容 ID' });
        return;
      }

      const content = await ContentsModel.findById(contentId);
      if (!content) {
        res.status(404).json({ code: 'NOT_FOUND', message: '内容不存在' });
        return;
      }

      const result = await FavoritesModel.toggle(userId, contentId);
      res.json({
        code: 'SUCCESS',
        data: result,
        message: result.action === 'added' ? '已收藏' : '已取消收藏',
      });
    } catch (error) {
      logger.error('切换收藏状态失败:', error);
      res.status(500).json({ code: 'INTERNAL_ERROR', message: '收藏操作失败' });
    }
  }

  /**
   * 查询收藏状态
   * GET /api/favorites/:contentId/status
   */
  static async getStatus(req: Request, res: Response): Promise<void> {
    try {
      const userId = req.session?.userId;
      if (!userId) {
        res.status(401).json({ code: 'UNAUTHORIZED', message: '请先登录' });
        return;
      }

      const contentId = parsePositiveContentId(req.params.contentId);
      if (contentId === null) {
        res.status(400).json({ code: 'VALIDATION_ERROR', message: '无效的内容 ID' });
        return;
      }

      const isFavorited = await FavoritesModel.isFavorited(userId, contentId);
      res.json({
        code: 'SUCCESS',
        data: { isFavorited },
        message: '获取收藏状态成功',
      });
    } catch (error) {
      logger.error('获取收藏状态失败:', error);
      res.status(500).json({ code: 'INTERNAL_ERROR', message: '获取收藏状态失败' });
    }
  }
}
```

4. 切换收藏处理函数：
```typescript
async function handleToggleFavorite() {
  if (!userStore.isLoggedIn || !content.value) return
  if (favoriteLoading.value) return // 防竞态重复点击

  const rawId = route.params.id
  favoriteLoading.value = true
  try {
    const res = await toggleFavorite(content.value.id)
    if (!isMounted.value || route.params.id !== rawId) return
    if (res.code === 'SUCCESS') {
      isFavorited.value = res.data.isFavorited
      ElMessage.success(res.data.action === 'added' ? '已收藏' : '已取消收藏')
    }
  } catch (err: any) {
    if (!isMounted.value || route.params.id !== rawId) return
    const status = err?.response?.status
    if (status === 401) {
      ElMessage.warning('登录已过期，请重新登录')
      await userStore.logout()
      router.push('/login')
      return
    }
    ElMessage.error('操作失败，请稍后重试')
    // 注意：不翻转 isFavorited，保持服务器真实状态
  } finally {
    if (isMounted.value && route.params.id === rawId) {
      favoriteLoading.value = false
    }
  }
}
```

### 接口契约（前后端约定）

| 接口 | 方法 | 路径 | 请求体 | 响应 data |
|------|------|------|--------|-----------|
| 切换收藏 | POST | `/api/favorites/:contentId/toggle` | 无 | `{ action: 'added'\|'removed', isFavorited: boolean }` |
| 查询状态 | GET | `/api/favorites/:contentId/status` | 无 | `{ isFavorited: boolean }` |

**错误码：**
- `400 VALIDATION_ERROR` — contentId 非正整数
- `401 UNAUTHORIZED` — 未登录 / Session 过期
- `404 NOT_FOUND` — 内容不存在（仅 toggle 接口）
- `500 INTERNAL_ERROR` — 服务器异常

### 性能考虑

- 收藏状态查询与 neighbors 查询并发，不增加额外串行延迟
- 收藏按钮点击无需查询列表页所有内容的收藏状态（避免 N+1）
- `FavoritesModel.toggle` 内部先 `isFavorited` 再 `add/remove`，2 次 SQL；若未来量大可优化为单条 `INSERT ... ON DUPLICATE KEY UPDATE`，**当前 story 不做此优化**

### 安全考虑

- 所有收藏接口必须 session 登录态校验，禁止匿名调用
- 用户只能操作自己的收藏（`userId` 来自 session，不可被前端参数污染）
- contentId 必须为正整数，防止 SQL 注入或类型混淆
- `FavoritesModel` 使用参数化查询（已就位），本 story 不需要修改

### 测试要求

- 后端：jest 单元测试覆盖所有 controller 分支（详见 Tasks）
- 后端：禁止连接真实数据库，必须 mock `FavoritesModel` 和 `ContentsModel`
- 前端：手动测试以下场景：
  1. 登录用户在详情页看到收藏按钮
  2. 点击收藏 → 按钮变「已收藏」→ 提示「已收藏」
  3. 刷新页面 → 按钮仍为「已收藏」（状态持久化）
  4. 再次点击 → 按钮变「收藏」→ 提示「已取消收藏」
  5. 退出登录 → 进入详情页 → 不显示收藏按钮
  6. 未登录直接调用 `POST /api/favorites/1/toggle` → 401
  7. 快速连续点击按钮 → 不会出现状态错乱（loading 期间禁用）
  8. 内容不存在 (`/contents/999999`) → 404 页面，不发起收藏查询
  9. Session 过期（手动清 cookie）后点击收藏 → 提示并跳转登录

## Previous Story Intelligence

### Story 2.4 学到的经验

- **marked.parse + v-html 风险**：通过 `DOMPurify.sanitize` 净化，`{ async: false }` 显式声明同步模式 — 本 story 不涉及 HTML 渲染，无需重复
- **findNeighbors 中 JSON.parse 异常**：模型层需 try/catch — 本 story 直接调用现有 FavoritesModel，无 JSON.parse 风险
- **el-tag type 强转 any**：必须用类型断言 `as TagType` 或精确类型映射 — 收藏按钮使用 `<el-button :type="isFavorited ? 'warning' : 'default'">`，类型为字符串字面量，安全
- **404 错误归因不精确**：详情页 catch 块需区分接口 404 与 500 — 本 story 收藏接口 401 比 404 更常见，需精确处理 401
- **watch route.params.id 竞态**：必须 `isMounted` + `rawId` 双重守卫 — 本 story 复用同样守卫
- **内容不存在时仍并发查询 neighbors**：已修复为先校验 content 再发其他请求 — 本 story 收藏状态查询同样依赖 content 加载成功
- **marked.parse 类型强制转换不安全**：`{ async: false }` 显式声明 — 本 story 不涉及
- **getNeighbors 测试未覆盖 500**：本 story favorites controller 测试必须覆盖 500 异常分支
- **ContentCard 模板中直接用 $router**：必须在 script setup 中 `import { useRouter } from 'vue-router'` — 本 story 修改 ContentDetailView，其已使用 `useRouter()`，无需改动
