# Story 0.4: 环境变量配置

## 📖 用户故事

**As a** 开发者  
**I want** 配置环境变量模板  
**So that** 敏感信息不会被提交到代码仓库

## ✅ 验收标准

**Given** 项目需要外部服务凭证  
**When** 创建 .env.example 模板  
**Then** 包含数据库配置项  
**And** 包含微信 OAuth 配置项  
**And** 包含 Claude API 配置项  
**And** .env 已加入 .gitignore

## 🏗️ 架构要求

### 技术栈规范
- 前端：Vue 3 + TypeScript + Vite
- 后端：Express + TypeScript
- 数据库：MySQL
- AI 服务：Claude API
- 认证：微信 OAuth

### 文件结构要求
```
project-root/
├── .env.example          # 环境变量模板（需创建）
├── .env                  # 实际环境变量（已加入 .gitignore）
├── backend/
│   ├── src/
│   │   └── config/       # 配置模块目录
│   │       └── env.ts    # 环境变量验证和加载（需创建）
├── frontend/
│   └── .env.example      # 前端环境变量模板（需创建）
└── .gitignore           # 确保 .env 被忽略
```

## 📋 具体实现要求

### 1. 后端环境变量配置 (backend/.env.example)

```bash
# Database Configuration
DB_HOST=localhost
DB_PORT=3306
DB_NAME=deployment_learning
DB_USER=your_db_user
DB_PASSWORD=your_db_password

# WeChat OAuth Configuration
WECHAT_APP_ID=your_wechat_app_id
WECHAT_APP_SECRET=your_wechat_app_secret
WECHAT_REDIRECT_URI=http://localhost:3000/api/auth/wechat/callback

# Claude API Configuration
CLAUDE_API_KEY=your_claude_api_key
CLAUDE_API_URL=https://api.anthropic.com/v1/messages

# Server Configuration
PORT=3000
NODE_ENV=development

# Session Configuration
SESSION_SECRET=your_session_secret_key
SESSION_MAX_AGE=86400000  # 24 hours

# CORS Configuration
CORS_ORIGIN=http://localhost:5173

# Logging Configuration
LOG_LEVEL=info
LOG_FORMAT=dev
```

### 2. 前端环境变量配置 (frontend/.env.example)

```bash
# API Configuration
VITE_API_BASE_URL=http://localhost:3000/api
VITE_WECHAT_APP_ID=your_wechat_app_id

# Development Configuration
VITE_PORT=5173
VITE_HOST=localhost

# Feature Flags
VITE_ENABLE_AI_CHAT=true
VITE_ENABLE_DECISION_TREE=true
```

### 3. 环境变量验证模块 (backend/src/config/env.ts)

```typescript
import { cleanEnv, str, port, url } from 'envalid';

export const env = cleanEnv(process.env, {
  // Database
  DB_HOST: str({ default: 'localhost' }),
  DB_PORT: port({ default: 3306 }),
  DB_NAME: str({ default: 'deployment_learning' }),
  DB_USER: str(),
  DB_PASSWORD: str(),

  // WeChat
  WECHAT_APP_ID: str(),
  WECHAT_APP_SECRET: str(),
  WECHAT_REDIRECT_URI: url(),

  // Claude API
  CLAUDE_API_KEY: str(),
  CLAUDE_API_URL: url({ default: 'https://api.anthropic.com/v1/messages' }),

  // Server
  PORT: port({ default: 3000 }),
  NODE_ENV: str({ choices: ['development', 'production', 'test'], default: 'development' }),

  // Session
  SESSION_SECRET: str(),
  SESSION_MAX_AGE: str({ default: '86400000' }),

  // CORS
  CORS_ORIGIN: str(),

  // Logging
  LOG_LEVEL: str({ choices: ['debug', 'info', 'warn', 'error'], default: 'info' }),
  LOG_FORMAT: str({ choices: ['dev', 'prod'], default: 'dev' })
});
```

## 🔧 开发步骤

1. **创建 .env.example 文件**
   - 在项目根目录创建 `.env.example`
   - 包含所有必需的环境变量配置项
   - 使用示例值，不要包含真实敏感信息

2. **创建前端环境变量模板**
   - 在 `frontend/` 目录创建 `.env.example`
   - 配置前端需要的环境变量

3. **安装环境变量验证库**
   ```bash
   cd backend
   npm install envalid
   npm install -D @types/envalid
   ```

4. **创建环境变量验证模块**
   - 创建 `backend/src/config/env.ts`
   - 实现环境变量验证和类型安全访问

5. **更新 .gitignore**
   - 确保 `.env` 文件被加入 `.gitignore`
   - 确保 `frontend/.env` 被加入 `.gitignore`

6. **创建配置加载模块**
   - 创建 `backend/src/config/index.ts`
   - 导出所有配置项

## ⚠️ 注意事项

1. **安全要求**
   - 永远不要在代码中硬编码敏感信息
   - 确保 .env 文件不会被提交到版本控制
   - 使用强密码和密钥

2. **开发环境**
   - 使用开发环境的 API 密钥
   - 配置本地数据库连接
   - 设置适当的 CORS 策略
