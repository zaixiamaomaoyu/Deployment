# Story 2.4: 内容详情页

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 用户,
I want 查看内容的详细说明和示例,
so that 我可以深入学习该知识点。

## Acceptance Criteria

1. **Given** 用户在内容列表页点击内容卡片  
   **When** 页面跳转  
   **Then** 进入 `/contents/:id` 详情页

2. **Given** 进入详情页  
   **When** 页面加载完成  
   **Then** 显示内容标题、领域标签、层级标签、更新时间

3. **Given** 进入详情页  
   **When** 页面加载完成  
   **Then** 显示完整的知识正文（Markdown 渲染）

4. **Given** 内容包含代码示例  
   **When** 页面加载完成  
   **Then** 以代码块形式展示代码示例  
   **And** 每个代码块支持一键复制

5. **Given** 详情页已加载  
   **When** 查看页面底部  
   **Then** 显示上一篇/下一篇导航链接  
   **And** 点击可跳转到对应内容详情

6. **Given** 用户访问不存在的内容 ID  
   **When** 页面加载  
   **Then** 显示 404 友好提示  
   **And** 提供「返回内容列表」链接

### 技术实现要点

**后端 `findNeighbors` 实现：**
```typescript
static async findNeighbors(id: number): Promise<{ prev: Content | null; next: Content | null }> {
  const [prevResult, nextResult] = await Promise.all([
    DatabaseService.query<Content[]>(
      'SELECT * FROM contents WHERE id < ? ORDER BY id DESC LIMIT 1',
      [id]
    ),
    DatabaseService.query<Content[]>(
      'SELECT * FROM contents WHERE id > ? ORDER BY id ASC LIMIT 1',
      [id]
    ),
  ]);

  const prev = prevResult[0] || null;
  const next = nextResult[0] || null;

  // 必须解析 JSON 字段
  [prev, next].forEach(item => {
    if (item) {
      if (item.examples) item.examples = JSON.parse(item.examples);
      if (item.tags) item.tags = JSON.parse(item.tags);
    }
  });

  return { prev, next };
}
```
- 注意：此实现按全局 ID 顺序找相邻。后续如需改为「同 domain 内相邻」，可扩展 WHERE 条件加 `domain = (SELECT domain FROM contents WHERE id = ?)`。

## Previous Story Intelligence

### Story 2.1 学到的经验

- **ContentsModel 完整复用**：findAll / findById 已就绪，不要创建新查询逻辑
- **参数验证必须严格**：page/limit 已做正整数校验，ID 校验同样严格
- **类型精确化**：`examples` / `tags` 使用 `unknown[]` / `string[]`，不要在 story 中降级为 any

### Story 2.2 学到的经验

- **统一入口函数**：筛选条件变化时统一调用 `loadData()`，避免重复请求
- **parseLevel 边界处理**：`value == null || value === ''` 才返回 undefined
- **AbortController 并发竞态**：快速连续触发时 `finally` 中 `abortController = null` 可能覆盖新实例，当前代码已存在此问题，本 Story 不涉及列表页不引入新修复

### Story 2.3 学到的经验

- **统一 loadData() 入口**：所有筛选条件变化（domain/level/search）都应调用同一个 `loadData()`
- **debounce 搜索输入**：使用原生 setTimeout，清理 timer 防止内存泄漏
- **HighlightText 组件**：安全实现无 v-html，使用 `mark` + 条件渲染
- **parseSearch 边界**：`typeof value === 'object'` 时返回 undefined，防止数组/对象型 query param
- **try/catch 包裹 new RegExp**：无效 Unicode 时优雅降级
