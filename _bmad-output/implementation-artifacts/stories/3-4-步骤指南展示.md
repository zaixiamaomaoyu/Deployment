# Story 3.4: 步骤指南展示

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

作为用户,
我希望查看推荐方案的详细步骤指南,
以便我可以按步骤完成部署。

## Acceptance Criteria

1. **Given** 用户点击「查看步骤指南」
   **When** 进入步骤指南页
   **Then** 显示分步骤的操作指南
   **And** 每步骤包含描述、截图、代码
   **And** 支持一键复制命令
   **And** 显示预计完成时间

2. **Given** 步骤指南页加载
   **When** 显示某方案的步骤
   **Then** 显示方案名称和简介（从 deploymentPlans 读取）
   **And** 显示方案特点（pros/cons/suitableFor，用 el-tag/el-alert 展示）

3. **Given** 用户阅读步骤指南
   **When** 找到需要复制的命令
   **Then** 命令行区域显示代码块
   **And** 显示「一键复制」按钮
   **And** 点击复制后显示成功提示
   **And** 复制成功后按钮状态变为「已复制」

4. **Given** 用户在移动端（宽度 < 768px）
   **When** 浏览步骤指南
   **Then** 步骤卡片垂直堆叠
   **And** 代码块支持横向滚动
   **And** 按钮区域可点击

5. **Given** 步骤指南页访问
   **When** 没有提供 planId 参数（或 planId 无效）
   **Then** 显示友好错误：「未找到该方案的步骤指南，请重新选择」
   **And** 提供「返回决策树」按钮

6. **Given** 步骤指南包含需要外部链接
   **When** 显示外部链接
   **Then** 链接指向 deploymentPlans 中的 externalUrl
   **And** 使用 el-link 组件展示

7. **Given** 步骤指南页加载完成
   **When** 渲染页面
   **Then** 使用 CSS 变量控制样式（--primary-color 等）
   **And** 所有面向用户的文案使用简体中文

### 关键复用点（禁止重复造轮子）

- **不要新建 store**：本组件为纯展示组件，数据来自父组件（或路由参数），**禁止**创建 Pinia store。
- **不要新增依赖**：技术栈已包含 `vue@3.4` + `element-plus@2.13` + `@vue/test-utils@2.4` + `vitest@2.1`，禁止引入额外工具库。
- **数据来源**：方案详情从 `deploymentPlans[planId]` 读取（Story 3-2 交付的静态数据），不是 API。
- **类型导出位置**：类型在 `frontend/src/types/` 目录，与 `architecture.md` 第 353-405 行约定一致。
- **CSS 变量复用**：使用 `architecture.md` 中定义的全局变量（`--primary-color`、`--spacing-md` 等），禁止新建主题变量。
- **测试组织**：参考 `frontend/src/views/__tests__/FavoritesView.spec.ts` 测试组织模式。
- **Element Plus 组件**：方案卡片使用 `<el-card>`，特点使用 `<el-alert>` + `<el-tag>`，按钮使用 `<el-button>`。
- **中文文案**：所有面向用户的字段（`planName`、`summary`、`pros`、`cons`、`suitableFor`）使用简体中文。
- **错误处理**：`planId` 不存在时显示友好错误，提供「返回决策树」按钮，不抛出 JS 错误。

**工具函数（`src/utils/copy-to-clipboard.ts`）：**
```typescript
export async function copyToClipboard(text: string): Promise<void> {
  // 现代浏览器 API
  if (navigator.clipboard && navigator.clipboard.writeText) {
    try {
      await navigator.clipboard.writeText(text)
      return
    } catch (error) {
      // Fallback
    }
  }

  // 旧浏览器 fallback
  const textArea = document.createElement('textarea')
  textArea.value = text

  // 避免滚动到底部
  textArea.style.position = 'fixed'
  textArea.style.left = '-999999px'

  document.body.appendChild(textArea)
  textArea.focus()
  textArea.select()

  try {
    const successful = document.execCommand('copy')
    if (!successful) {
      throw new Error('execCommand failed')
    }
  } catch (error) {
    throw error
  } finally {
    document.body.removeChild(textArea)
  }
}
```

**关键设计决策：**

1. **数据源选择**：从 `deploymentPlans[planId]` 读取方案详情，而非从 API 获取。理由：
   - 部署方案是静态配置，不需要后端支持
   - Story 3-2 已提供完整的 deploymentPlans 数据
   - 保持前端独立，无需额外 API 请求

2. **错误处理**：`planId` 不存在时显示友好错误而非崩溃。用户可能：
   - 直接访问步骤指南页 URL（带无效 planId）
   - 数据文件被误改/删除
   - 显示错误并提供「返回决策树」按钮，引导用户回到决策树

3. **步骤内容**：当前 Story 仅展示基础信息（方案名称、简介、特点），具体步骤内容由 Story 3-5 交付。本 Story 提供：
   - 基础框架和路由
   - 错误处理
   - 复制功能
   - 移动端适配

4. **样式复用**：使用 Element Plus 组件（`el-card` / `el-alert` / `el-tag` / `el-button`），CSS 变量控制颜色和间距，保持与项目一致。

### 接口契约（组件 props/emits）

| 接口 | 类型 | 说明 |
|------|------|------|
| Prop `planId` | `string` | 部署方案的 ID，从决策结果页传入 |
| Emit `go-back` | `() => void` | 用户点击「返回决策树」时触发 |

### 性能考虑

- `deploymentPlans` 是纯对象，无响应式开销，直接 `import` 即可。
- 方案详情在页面初始化时计算一次（`computed`），缓存复用。
- 复制功能使用同步 API（`navigator.clipboard.writeText`），无异步开销。
- 文件大小 < 5KB（gzip 后 < 2KB），无需懒加载。

### 安全考虑

- 所有文案来自前端硬编码数据（Story 3-2 设计），无用户输入渲染，无 XSS 风险。
- `externalUrl` 使用官方链接，禁止 affiliate 链接。

- **组件测试**：使用 `@vue/test-utils` 的 `mount`，Mock `deploymentPlans` 导入。
- **覆盖率目标**：组件渲染分支 ≥ 80%。
- **手动测试场景**：

  2. 移动端（375x667）布局正常，按钮区域可点击
