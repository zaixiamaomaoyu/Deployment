### 数据库设计规范

**表命名规范：**
- 使用小写字母和下划线
- 表名使用复数形式（users, contents）
- 关联表使用下划线连接（user_progress）

**字段命名规范：**
- 主键统一使用 `id`
- 外键使用 `表名_id` 格式（user_id, content_id）
- 时间字段使用 `created_at`, `updated_at`
- 布尔字段使用 `is_` 前缀

### 核心表结构设计

**users 用户表：**
```sql
CREATE TABLE users (
  id INT PRIMARY KEY AUTO_INCREMENT,
  openid VARCHAR(255) UNIQUE NOT NULL COMMENT '微信 OpenID',
  role ENUM('user', 'admin') DEFAULT 'user' COMMENT '用户角色',
  nickname VARCHAR(100) COMMENT '用户昵称',
  avatar_url VARCHAR(500) COMMENT '头像URL',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_openid (openid),
  INDEX idx_role (role)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**contents 知识内容表：**
```sql
CREATE TABLE contents (
```

### 数据库连接配置

**src/config/database.ts 配置：**
```typescript
import mysql from 'mysql2/promise';
import dotenv from 'dotenv';

dotenv.config();

// 数据库连接池配置
export const dbConfig = {
  host: process.env.DB_HOST || 'localhost',
  user: process.env.DB_USER || 'root',
  password: process.env.DB_PASSWORD || '',
  database: process.env.DB_NAME || 'deployment_learning',
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0,
  acquireTimeout: 60000,
  timeout: 60000
};

// 创建连接池
export const pool = mysql.createPool(dbConfig);

// 数据库连接测试
export async function testConnection(): Promise<boolean> {
  try {
    const connection = await pool.getConnection();
    await connection.ping();
    connection.release();
    console.log('✅ 数据库连接测试成功');
    return true;
  } catch (error) {
    console.error('❌ 数据库连接测试失败:', error);
    return false;
  }
}

// 获取数据库连接
export async function getConnection() {
  return await pool.getConnection();
}

// 关闭连接池
export async function closePool() {
  await pool.end();
}
```

**src/services/database.service.ts 基础服务：**
```typescript
import { pool } from '../config/database';
import { RowDataPacket, ResultSetHeader } from 'mysql2/promise';

export class DatabaseService {
  // 基础查询方法
  static async query<T extends RowDataPacket[]>(
    sql: string, 
    params?: any[]
  ): Promise<T> {
    const [rows] = await pool.execute<T>(sql, params);
    return rows;
  }

  // 基础执行方法
  static async execute(sql: string, params?: any[]): Promise<ResultSetHeader> {
    const [result] = await pool.execute<ResultSetHeader>(sql, params);
    return result;
  }

  // 事务处理
  static async transaction<T>(callback: (connection: any) => Promise<T>): Promise<T> {
    const connection = await pool.getConnection();
    
    try {
      await connection.beginTransaction();
      const result = await callback(connection);
      await connection.commit();
      return result;
    } catch (error) {
      await connection.rollback();
      throw error;
    } finally {
      connection.release();
    }
  }

  // 批量插入
  static async batchInsert(sql: string, values: any[][]): Promise<ResultSetHeader> {
    const [result] = await pool.query<ResultSetHeader>(sql, [values]);
    return result;
  }
}
```

### 数据库初始化脚本

**scripts/init-database.ts 初始化脚本：**
```typescript
import { pool } from '../src/config/database';
import fs from 'fs';
import path from 'path';

async function initializeDatabase() {
  try {
    console.log('🚀 开始初始化数据库...');
    
    // 读取SQL脚本
    const sqlScript = fs.readFileSync(
      path.join(__dirname, '../scripts/database-init.sql'), 
      'utf8'
    );
    
    // 执行SQL脚本
    const connection = await pool.getConnection();
    
    try {
      // 分割SQL语句并执行
      const statements = sqlScript.split(';').filter(stmt => stmt.trim());
      
      for (const statement of statements) {
        if (statement.trim()) {
          await connection.query(statement);
        }
      }
      
      console.log('✅ 数据库初始化完成');
    } finally {
      connection.release();
    }
    
  } catch (error) {
    console.error('❌ 数据库初始化失败:', error);
    process.exit(1);
  } finally {
    await pool.end();
  }
}

// 执行初始化
initializeDatabase();
```

### 性能优化建议

1. **索引优化**：
   - 为常用查询字段添加索引
   - 复合索引按照查询频率排序
   - 避免过度索引影响写入性能

2. **连接池配置**：
   - 根据并发量调整 connectionLimit
   - 设置合理的超时时间
   - 监控连接池使用情况

3. **查询优化**：
   - 使用连接池避免频繁创建连接
   - 批量操作使用事务
   - 复杂查询添加适当的索引

### 安全考虑

1. **SQL注入防护**：
   - 始终使用参数化查询
   - 避免字符串拼接SQL
   - 对用户输入进行验证和清理

2. **敏感数据保护**：
   - 不存储明文密码（仅存储微信OpenID）
   - 使用SSL连接数据库（生产环境）
   - 限制数据库用户权限

3. **错误处理**：
   - 不向用户暴露详细错误信息
   - 记录错误日志用于调试
   - 实现优雅的降级处理

### 反模式警告

```sql
-- ❌ 避免：不使用外键约束
CREATE TABLE user_progress (
  user_id INT,  -- 缺少外键约束
  content_id INT
);

-- ✅ 推荐：使用外键约束确保数据完整性
CREATE TABLE user_progress (
  user_id INT,
  content_id INT,
  CONSTRAINT fk_user FOREIGN KEY (user_id) REFERENCES users(id),
  CONSTRAINT fk_content FOREIGN KEY (content_id) REFERENCES contents(id)
);

-- ❌ 避免：不使用索引
CREATE TABLE contents (
  title VARCHAR(200)  -- 查询字段无索引
);

-- ✅ 推荐：为查询字段添加索引
CREATE TABLE contents (
  title VARCHAR(200),
  INDEX idx_title (title)
);
```
