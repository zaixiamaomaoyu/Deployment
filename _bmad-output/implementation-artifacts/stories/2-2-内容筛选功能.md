# Story 2.2: 内容筛选功能

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 用户,
I want 按领域和层级筛选内容,
so that 我可以快速找到感兴趣的内容。

## Acceptance Criteria

1. **Given** 内容列表已加载  
   **When** 选择领域筛选条件  
   **Then** 只显示该领域的内容

2. **Given** 内容列表已加载  
   **When** 选择层级筛选条件  
   **Then** 只显示该层级的内容

3. **Given** 用户已选择领域和层级  
   **When** 内容加载  
   **Then** 只显示同时满足两个条件的内容（组合筛选）

4. **Given** 筛选后无匹配内容  
   **When** 页面展示结果  
   **Then** 显示友好空状态提示（如「该筛选条件下暂无内容」）

5. **Given** 用户切换筛选条件  
   **When** 新请求发出  
   **Then** 自动取消之前的未完成请求（防止竞态覆盖）

### 技术实现要点

**后端 level 参数验证：**
```typescript
function parseLevel(value: unknown): number | undefined {
  if (value === undefined || value === '') return undefined;
  const num = Number(value);
  if (Number.isNaN(num) || !Number.isInteger(num) || num < 1 || num > 5) {
    return undefined; // 或返回 400 错误
  }
  return num;
}
```
- 建议：无效 level 返回 400 `VALIDATION_ERROR`，与无效 domain 行为一致。

**前端层级选项定义：**
```typescript
const levelOptions = [
  { label: '全部层级', value: undefined },
  { label: 'Lv1', value: 1 },
  { label: 'Lv2', value: 2 },
  { label: 'Lv3', value: 3 },
  { label: 'Lv4', value: 4 },
  { label: 'Lv5', value: 5 },
]
```

**ContentsView 筛选逻辑：**
- `activeDomain`（string）+ `activeLevel`（number | undefined）共同决定请求参数
- `fetchContents(domain?: string, level?: number)` 同时传递两个参数
- 避免 `watch` + `onMounted` + 事件处理重复触发请求（Story 2.1 review 发现的问题）
- 建议：统一用一个 `loadData()` 函数，在 `onMounted`、tab 切换、层级变化时调用，内部读取 `activeDomain` 和 `activeLevel` 当前值

**空状态提示文案：**
```
筛选条件下暂无内容，请尝试其他组合
```

### 测试要求

- 后端：验证 `GET /api/contents?domain=build&level=2` 返回正确组合结果
- 后端：验证无效 `level=0` 或 `level=abc` 返回 400 或忽略
- 前端：手动测试领域 + 层级组合筛选、空状态、快速切换不闪动

### 性能考虑

- 层级筛选不涉及额外索引（目前表结构无复合索引），数据量小（<1000条）时无性能问题
- 保留默认 `limit = 20`
