# Story 1.1: 微信扫码登录前端

## 📖 用户故事

**As a** 未登录用户
**I want** 通过微信扫码登录系统
**So that** 我可以使用平台的完整功能

## ✅ 验收标准

1. **Given** 用户未登录 **When** 访问登录页面 **Then** 显示微信扫码登录按钮
2. **And** 点击后跳转到微信授权页面
3. **And** 授权成功后跳转回首页并显示登录状态

## 🏗️ 架构要求

### 技术栈规范
- 前端：Vue 3 + TypeScript + Vite + Element Plus
- 路由：Vue Router 4
- 状态管理：Pinia
- HTTP：Axios

### 文件结构要求
```
frontend/src/
├── views/
│   └── Login.vue              # 登录页面（需创建）
├── components/
│   └── WechatLoginButton.vue  # 微信登录按钮组件（需创建）
├── stores/
│   └── user.ts                # 用户状态管理（需创建）
├── api/

└── router/
    └── index.ts               # 需添加登录路由
```

## 📋 具体实现要求

### 1. 微信 OAuth 流程

微信网页授权流程（OAuth2）：
1. 前端引导用户访问微信授权链接：`https://open.weixin.qq.com/connect/qrconnect?appid={APPID}&redirect_uri={REDIRECT_URI}&response_type=code&scope=snsapi_login&state={STATE}#wechat_redirect`
2. 用户扫码确认后，微信重定向到 `redirect_uri?code=CODE&state=STATE`
3. 后端用 `code` 换取 `access_token` 和 `openid`
4. 后端设置 Session 并返回登录状态
5. 前端跳转到首页

### 2. 登录页面 (Login.vue)

```vue
<template>
  <div class="login-page">
    <el-card class="login-card">
      <h2>欢迎登录</h2>
      <p>使用微信扫码登录 Deployment Learning</p>
      <WechatLoginButton />
    </el-card>
  </div>
</template>
```

要求：
- 居中布局，响应式适配
- 显示品牌 Logo 和描述
- 微信登录按钮带微信品牌样式（绿色）

### 3. 微信登录按钮组件 (WechatLoginButton.vue)

要求：
- 点击后跳转到微信授权 URL
- 使用 `window.location.href` 跳转（非 axios 请求）
- 授权 URL 从环境变量 `VITE_WECHAT_APP_ID` 和配置中拼接
- 生成随机 `state` 参数防止 CSRF

### 4. 用户状态管理 (user.ts)

使用 Pinia 管理用户登录状态：
- `isLoggedIn`: boolean
- `userInfo`: { openid, nickname, avatarUrl, role } | null
- `login()`: 处理登录回调，调用后端获取用户信息
- `logout()`: 清除登录状态
- `checkLoginStatus()`: 页面加载时检查 Session 是否有效

### 5. 认证 API (auth.ts)

```typescript
// 获取当前登录用户信息
GET /api/auth/me

// 退出登录
POST /api/auth/logout
```

### 6. 路由配置

```typescript
const routes = [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/views/Login.vue'),
  },
  {
    path: '/auth/callback',
    name: 'AuthCallback',
    component: () => import('@/views/AuthCallback.vue'),
    // 处理微信回调：解析 code 和 state，调用后端完成登录
  },
  // ... 其他路由
]
```

### 7. 回调处理页面 (AuthCallback.vue)

- 从 URL 查询参数获取 `code` 和 `state`
- 校验 `state` 是否匹配（防止 CSRF）
- 发送请求到后端 `/api/auth/wechat/callback?code=CODE`
- 后端返回用户信息后，更新 Pinia store
- 跳转到首页或之前的页面

## ⚠️ 注意事项

1. **安全性**：
   - `state` 参数必须随机生成并存储在 sessionStorage 中，回调时校验
   - 前端不处理 `code` 换取 `access_token`（由后端完成，防止 app_secret 泄露）

2. **开发环境**：
   - 微信授权需要配置合法的 `redirect_uri`，开发时可能需要内网穿透工具（如 ngrok）
   - 开发阶段可模拟回调流程进行测试

3. **前置依赖**：
   - Story 0.1（前端初始化）已完成
   - Story 1.2（微信 OAuth 后端集成）需配合联调
