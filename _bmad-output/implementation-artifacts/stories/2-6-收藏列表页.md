# Story 2.6: 收藏列表页

Status: 已完成

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 登录用户,
I want 查看我收藏的内容列表,
so that 我可以快速访问感兴趣的内容。

## Acceptance Criteria

1. **Given** 用户已登录且有收藏内容
   **When** 访问 `/favorites` 页面
   **Then** 显示所有收藏的内容卡片列表

2. **Given** 收藏列表已加载
   **When** 查看列表卡片
   **Then** 卡片显示内容标题、领域标签、层级标签、简介
   **And** 点击卡片跳转到 `/contents/:id` 详情页

3. **Given** 卡片列表中包含收藏项
   **When** 点击卡片上的收藏按钮（或直接点击卡片）
   **Then** 取消收藏该内容
   **And** 卡片从列表中移除
   **And** 显示 `ElMessage.success('已取消收藏')`

4. **Given** 用户已登录但没有收藏内容
   **When** 访问收藏页面
   **Then** 显示空状态提示（如「您还没有收藏任何内容」）
   **And** 显示「去浏览内容」按钮，点击跳转到内容列表页

5. **Given** 用户未登录
   **When** 访问 `/favorites` 页面
   **Then** 重定向到登录页（携带 `redirect=/favorites` query）

6. **Given** 收藏接口返回 401（Session 过期）
   **When** 用户尝试访问收藏列表
   **Then** 提示「登录已过期，请重新登录」
   **And** 清除前端登录状态
   **And** 跳转到登录页

7. **Given** 收藏列表加载中
   **When** 页面显示 loading 状态
   **Then** 显示骨架屏或加载动画

8. **Given** 收藏列表中内容较多（>10 条）
   **When** 页面滚动到底部
   **Then** 支持分页加载（实现 basic pagination）

9. **Given** 用户快速连续点击取消收藏按钮（竞态）
   **When** 第一次请求尚未返回
   **Then** 后续点击应被忽略（按钮 loading 或禁用），防止重复请求造成状态错乱

**后端 FavoritesController.list 方法：**
```typescript
import { Request, Response } from 'express';
import { FavoritesModel } from '../models/favorites.model';
import { logger } from '../utils/logger';

function parsePositiveInteger(value: string | undefined, defaultValue: number, max: number): number {
  if (!value) return defaultValue;
  const num = Number(value);
  if (Number.isNaN(num) || !Number.isInteger(num) || num < 1 || num > max) {
    return defaultValue; // 或返回 400 错误
  }
  return num;
}

export class FavoriteController {
  /**
   * 获取收藏列表（带分页）
   * GET /api/favorites?page=1&limit=10
   */
  static async list(req: Request, res: Response): Promise<void> {
    try {
      const userId = req.session?.userId;
      if (!userId) {
        res.status(401).json({ code: 'UNAUTHORIZED', message: '请先登录' });
        return;
      }

      const page = parsePositiveInteger(req.query.page, 1, 100);
      const limit = parsePositiveInteger(req.query.limit, 10, 100);

      const { favorites, total } = await FavoritesModel.findByUser(userId, page, limit);

      res.json({
        code: 'SUCCESS',
        data: { favorites, total },
        message: '获取收藏列表成功',
      });
    } catch (error) {
      logger.error('获取收藏列表失败:', error);
      res.status(500).json({ code: 'INTERNAL_ERROR', message: '获取收藏列表失败' });
    }
  }
}
```

**前端 FavoritesView.vue 结构建议：**
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { useRouter } from 'vue-router'
import { useUserStore } from '@/stores/user'
import { listFavorites, toggleFavorite } from '@/api/favorites'
import ContentCard from '@/components/ContentCard.vue'
import { Star } from '@element-plus/icons-vue'
import { ElMessage } from 'element-plus'

const router = useRouter()
const userStore = useUserStore()

const favorites = ref<Content[]>([])
const total = ref(0)
const page = ref(1)
const limit = ref(10)
const loading = ref(false)
let abortController: AbortController | null = null

async function loadFavorites() {
  if (abortController) abortController.abort()
  abortController = new AbortController()

  loading.value = true
  try {
    const res = await listFavorites(page.value, limit.value)
    if (res.code === 'SUCCESS') {
      favorites.value = res.data.favorites
      total.value = res.data.total
    }
  } catch (err: any) {
    if (err.name === 'AbortError') return
    const status = err?.response?.status
    if (status === 401) {
      ElMessage.warning('登录已过期，请重新登录')
      await userStore.logout()
      router.push('/login?redirect=/favorites')
    } else {
      ElMessage.error('加载失败，请稍后重试')
    }
  } finally {
    loading.value = false
  }
}

async function handleToggleFavorite(content: Content) {
  if (!userStore.isLoggedIn || loading.value) return

  const rawContentId = content.id
  loading.value = true
  try {
    const res = await toggleFavorite(content.id)
    if (!loading.value) return // loading 重置时不处理
    if (res.code === 'SUCCESS') {
      // 如果是取消收藏，从列表中移除
      if (res.data.action === 'removed') {
        favorites.value = favorites.value.filter(f => f.id !== rawContentId)
        ElMessage.success('已取消收藏')
      } else {
        ElMessage.success('已收藏')
      }
    }
  } catch (err: any) {
    if (!loading.value) return
    const status = err?.response?.status
    if (status === 401) {
      ElMessage.warning('登录已过期，请重新登录')
      await userStore.logout()
      router.push('/login?redirect=/favorites')
    } else {
      ElMessage.error('操作失败，请稍后重试')
    }
  } finally {
    loading.value = false
  }
}

function handleCardClick(content: Content) {
  router.push(`/contents/${content.id}`)
}

function loadMore() {
  page.value++
  loadFavorites()
}

onMounted(() => {
  if (userStore.isLoggedIn) {
    loadFavorites()
  } else {
    router.push({ path: '/login', query: { redirect: '/favorites' } })
  }
})
</script>

<template>
  <div class="favorites-page" v-loading="loading">
    <el-page-header @click="router.push('/contents')" style="margin-bottom: 20px;">
      <template #content>我的收藏</template>
      <template #extra>
        <el-button v-if="total === 0" @click="router.push('/contents')">去浏览内容</el-button>
      </template>
    </el-page-header>

    <el-empty v-if="!loading && favorites.length === 0" description="您还没有收藏任何内容">
      <el-button type="primary" @click="router.push('/contents')">去浏览内容</el-button>
    </el-empty>

    <div v-else class="favorites-grid">
      <ContentCard
        v-for="fav in favorites"
        :key="fav.id"
        :content="fav"
        @click="handleCardClick(fav)"
      >
        <template #extra>
          <el-button
            :type="fav.isFavorited ? 'warning' : 'default'"
            :icon="Star"
            :loading="loading"
            size="small"
            @click.stop="handleToggleFavorite(fav)"
          >
            {{ fav.isFavorited ? '已收藏' : '收藏' }}
          </el-button>
        </template>
      </ContentCard>
    </div>

    <div v-if="total > favorites.length" class="load-more">
      <el-button @click="loadMore" :loading="loading">加载更多</el-button>
    </div>
  </div>
</template>

<style scoped>
.favorites-page {
  padding: 24px;
}

.favorites-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  gap: 16px;
}

.load-more {
  margin-top: 24px;
  text-align: center;
}
</style>
```

**分页逻辑说明：**
- 后端：`FavoritesModel.findByUser(userId, page, limit)` 接受 page 和 limit 参数
- 前端：`page` 初始为 1，点击"加载更多"时 `page++`，向后端请求下一页
- 前端：`total` 记录总收藏数，当 `favorites.length < total` 时显示"加载更多"按钮

### 接口契约（前后端约定）

| 接口 | 方法 | 路径 | 请求参数 | 响应 data |
|------|------|------|---------|-----------|
| 获取收藏列表 | GET | `/api/favorites?page=1&limit=10` | `page`, `limit` | `{ favorites: Content[], total: number }` |

**错误码：**
- `400 VALIDATION_ERROR` — page/limit 非正整数或超出范围
- `401 UNAUTHORIZED` — 未登录 / Session 过期
- `500 INTERNAL_ERROR` — 服务器异常

### 性能考虑

- 收藏列表使用分页加载，默认每页 10 条，最大 100 条
- `FavoritesModel.findByUser` 已按 `created_at DESC` 排序
- 并发切换收藏列表页时使用 `AbortController` 取消未完成请求
- 取消收藏时立即从列表中移除，不重新请求全量数据（需注意移除后分页可能不匹配，可重置为第一页或保留当前分页）

### 安全考虑

- 所有收藏接口必须 session 登录态校验，禁止匿名调用
- 用户只能查看自己的收藏（`userId` 来自 session，不可被前端参数污染）
- `page` 和 `limit` 必须为正整数且合理范围，防止 SQL 注入或类型混淆
- `FavoritesModel.findByUser` 使用参数化查询（已就位）
